# CycleCare 2.3.0

- Adapt layouts to available width, system safe insets, keyboard and larger
  text, and place main navigation in a floating translucent dock.
- Add an introduction and dashboard for each tracking mode, with confirmation
  before changing mode and without deleting records. An optional ten-feature
  tour opens the real screens and can be paused or replayed.
- Bring the four approved companions and their 36 action films into Flutter.
  Connect optional daily tasks to actual observations, explicit water entry and
  once-per-day reward claims.
- Add an offline sourced-article helper and optional user-configured Gemini or
  an HTTPS-hosted compatible model. No shared provider key is bundled. Generated
  answers are educational and are not diagnoses or contraceptive advice.
- Add a separate partner dashboard, manual snapshots and consent-controlled
  online pairing. Live sync requires the configured server, deployed database
  migration, anonymous device authentication and two-device verification.
  When tracking records are deleted, active owner-side online links must be
  revoked first; previously exported copies cannot be recalled.

See [preview evidence](../preview-2.3.0.md), [assistant research](../assistant-models.md)
and [partner setup](../partner/connection-setup.md). The development-signed
side-by-side preview has its own app data; a future signed release uses the
existing production application ID and signing key.

# CycleCare v2.2.0

This release brings the approved Flutter redesign and four batches of reliability,
prediction transparency, useful records and supporting flows into one Android build.

- Fixed compact/large-text Home controls and calendar layouts while preserving
  the phase bar, every phase/window section, dark mode and reduced motion.
- Added contextual notification permission/recovery, system-settings access,
  scheduling reports, retry and local timezone handling. Cycle reminders now use
  estimated dates and advance notice instead of repeating every day. Restricted
  exact alarms fall back to approximate scheduling; system acceptance is reported
  separately from delivery.
- Added reversible forecast exclusions with optional reasons, shared forecast
  rules, history/settings explanations, cycle counts and observed variation.
  Retrospective date errors replay the actual estimator without future records.
- Added an offline cycle-health report with date/symptom selection, preview,
  copy and plain-text file sharing. Medication, tests and reproductive observations
  are off by default. Estimates are a separate optional section.
- Extended existing pain tracking with activity impact and retained pain-diary
  records, added descriptive symptom counts and coverage across recorded cycles,
  and linked informational care prompts to NHS sources.
- Start-only period logging keeps the end date unknown. Calendar editing records
  an end only when selected, and reports flag future end dates as unconfirmed.
- Added temperature measurement context without overwriting actual readings;
  preserved LH tests and cervical observations as observations. Temperature,
  LH and calendar estimates do not confirm ovulation or contraceptive safe days.
- Completed structured offline article rendering while preserving all 26 article
  IDs, text, sources, bookmarks and reading progress.
- Updated Android build portability, release checks, signature verification,
  checksums and actual Flutter UI evidence in GitHub Actions.

## Install

Download `cyclecare-v2.2.0.apk` from this release and open it on Android 7.0 or
later. Allow installation from the app/browser used to open the file if Android
asks. The AAB is for app-store distribution. `SHA256SUMS.txt` lists file checksums.

The release workflow uses the repository's existing signing key. Keep your records
and tracking backup before upgrading. Tracking backups cover periods, daily logs
and cycle preferences; auxiliary feature stores are outside that backup format.

## Evidence and limits

See [verification details](https://github.com/lekhanpro/cyclecare/blob/v2.2.0/docs/release-verification.md) and
[prediction evaluation criteria](https://github.com/lekhanpro/cyclecare/blob/v2.2.0/docs/prediction-evaluation.md). Historical replay
and regression tests establish engineering behavior on tested records, not clinical
validation. The companion film/mesh prototype, wearable connections and remote AI
remain outside the shipped implementation. Android controls final notification
delivery. No new health-data upload or automatic partner sharing was introduced.

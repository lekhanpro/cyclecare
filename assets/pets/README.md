# Original clay companions

Luna, Miso, Maple and Pip retain their approved original PNG artwork. The native
Flutter companion deforms one connected image mesh and plays the 36 authored,
muted, offline H.264 clips in `films/`. Nine actions exist for each character.
The unchanged film manifest records the original dimensions, durations and SHA-256
hashes. These films were recovered byte-for-byte from the approved redesign history.

The films were rendered from the original artwork with the continuous-image
Three.js reference, not a remote video-generation service. Live Flutter touches
interrupt playback; head, ear and paw responses deform the same artwork locally.
No cutout limb textures, replacement vector drawings or historical Rive studies
are used by the native renderer. Mood, level, growth and achievements remain saved
state; the original hero pose does not imply a separate illustrated growth set.

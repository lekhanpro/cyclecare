# Nunito

Used only by the brand tooling, which inlines these files as base64 `@font-face`
sources so `assets/brand/cyclecare-wordmark*.svg` rasterise identically on any
machine. The app itself loads Nunito at runtime through `google_fonts` and does
not read this directory.

Nunito by Vernon Adams, Cyreal and Jacques Le Bailly, licensed under the
[SIL Open Font License 1.1](https://openfontlicense.org/). Retrieved from
[Fontsource](https://fontsource.org/fonts/nunito), which redistributes the
[Google Fonts](https://fonts.google.com/specimen/Nunito) release.
